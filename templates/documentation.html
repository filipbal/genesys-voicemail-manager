Genesys Voicemail Manager - User Guide

Overview

Genesys Cloud enforces user-level ownership on voicemail media—administrators cannot access other users' voicemail recordings. This application provides a self-service portal where users can manage their own voicemails through a web browser.

Features

Authentication
  • OAuth 2.0 with PKCE - Secure browser-based authentication
  • Session-based tokens - Access tokens stored securely in server-side sessions
Voicemail Management
  • View voicemails - List all voicemails with caller info, date, duration, and read status
  • Download individual - Download single voicemail as WAV file
  • Download all - Export all voicemails as ZIP archive with metadata
  • Delete individual - Remove single voicemail with confirmation
  • Delete all - Bulk delete all voicemails with confirmation
  • Forward to user - Forward voicemail to another Genesys user
User Interface
  • Responsive design - Works on desktop and mobile devices
  • Dark/Light mode - Theme toggle for user preference
  • Real-time feedback - Toast notifications for all actions
  • Bulk selection - Checkbox selection for batch operations

How to Use

  1. Click the "Login with Genesys Cloud" button on the home page
  2. You will be redirected to Genesys Cloud login page
  3. Enter your Genesys credentials
  4. After successful authentication, you'll be redirected to your voicemail dashboard
Your password is never seen or stored by this application.

Individual Download:
  1. Find the voicemail you want to download
  2. Click the download icon next to it
  3. The WAV file will be downloaded to your computer
Download All:
  1. Click the "Download All" button at the top of the dashboard
  2. A ZIP file containing all voicemails and metadata will be downloaded

  1. Click the forward icon next to the voicemail
  2. A modal will appear with a search box
  3. Type the name or email of the recipient user
  4. Select the user from the search results
  5. Click "Forward" to send
Forwarded voicemails will appear in the recipient's Genesys voicemail inbox.

Individual Delete:
  1. Click the delete icon next to the voicemail
  2. Confirm the deletion in the popup dialog
Delete All:
  1. Click the "Delete All" button at the top of the dashboard
  2. Read the warning carefully
  3. Confirm to delete all voicemails
Warning: Deleted voicemails cannot be recovered!

Security

  • No password storage - Authentication handled entirely by Genesys Cloud OAuth
  • Token security - Access tokens stored only in server-side sessions
  • User isolation - Each user can only access their own voicemails
  • HTTPS required - All traffic encrypted
  • CSRF protection - OAuth state parameter prevents cross-site request forgery
  • Temporary files - Downloaded files cleaned up automatically

Troubleshooting

Problem Solution
Login fails or redirects incorrectly Clear your browser cache and try again. Ensure you're using the correct Genesys account.
No voicemails showing Your voicemail inbox may be empty. Check Genesys UI to confirm.
"Access denied" when downloading The voicemail may have been deleted. Try refreshing the page.
Forward not working Ensure the recipient user exists and has voicemail enabled.
Session expired Log out and log back in to get a fresh token.

API Endpoints

For developers and advanced users.

Endpoint Method Description
/api/voicemails GET List all voicemails (JSON)
/download/<id> GET Download single voicemail
/download-all GET Download all as ZIP
/api/delete/<id> DELETE Delete single voicemail
/api/delete-all DELETE Delete all voicemails
/api/forward/<id> POST Forward voicemail
/api/search/users GET Search users
/health GET Health check
