Genesys Voicemail Manager - User Guide

Overview

Genesys Cloud enforces user-level ownership on voicemail media—administrators cannot access other users' voicemail recordings. This application provides a self-service portal where users can manage their own voicemails through a web browser.

Features

Authentication
  • OAuth 2.0 with PKCE - Secure browser-based authentication
  • Session-based tokens - Access tokens stored securely in server-side sessions
Voicemail Management
  • View voicemails - List all voicemails with caller info, date, duration, and read status
  • Download individual - Download single voicemail as WAV file
  • Download bulk - Export multiple voicemails as ZIP archive with metadata
  • Delete individual - Remove single voicemail with confirmation
  • Delete bulk - Batch delete multiple voicemails with confirmation
  • Forward to user/group - Forward voicemail to another Genesys user or group

How to Use

  1. Select your Genesys Cloud region from the dropdown
  2. Click the "Login with Genesys Cloud" button
  3. You will be redirected to Genesys Cloud login page
  4. Enter your Genesys credentials
  5. After successful authentication, you'll be redirected to your voicemail dashboard
Your password is never seen or stored by this application.

Individual Download:
  1. Find the voicemail you want to download on the dashboard
  2. Click the download icon next to it
  3. The WAV file will be downloaded to your computer
Bulk Download:
  1. Click the "Download All" button on the dashboard
  2. Select the voicemails you want to download (or select all)
  3. Click "Download Selected"
  4. Wait for the download to complete - a progress indicator will show status
  5. A ZIP file containing all selected voicemails and metadata will be downloaded
Large downloads (500+ voicemails) may take 8-12 minutes. Please keep the window open during processing.

Forward Single Voicemail:
  1. Click the forward icon next to the voicemail on the dashboard
  2. A modal will appear with a search box
  3. Choose to forward to a User or Group
  4. Type the name or email of the recipient
  5. Select the recipient from the search results
  6. Click "Forward" to send
Bulk Forward:
  1. Click the "Forward All" button on the dashboard
  2. Select a recipient (user or group)
  3. Select the voicemails you want to forward
  4. Click "Forward Selected"
  5. Wait for the operation to complete
Forwarded voicemails will appear in the recipient's Genesys voicemail inbox.

Delete Single Voicemail:
  1. Click the delete icon next to the voicemail on the dashboard
  2. Confirm the deletion in the popup dialog
Bulk Delete:
  1. Click the "Delete All" button on the dashboard
  2. Select the voicemails you want to delete
  3. Click "Delete Selected"
  4. Read the warning carefully
  5. Confirm to delete the selected voicemails
Warning: Deleted voicemails cannot be recovered!

Security

  • No password storage - Authentication handled entirely by Genesys Cloud OAuth 2.0 with PKCE
  • No file storage - ZIP files created client-side in browser; voicemails never stored on server
  • Token security - Access tokens stored only in server-side sessions and cleared on logout
  • CSRF protection - OAuth state parameter prevents cross-site request forgery
  • User isolation - Each user can only access their own voicemails
  • HTTPS required - All traffic encrypted

Troubleshooting

Problem Solution
Login fails or redirects incorrectly Clear your browser cache and try again. Ensure you're using the correct Genesys account.
No voicemails showing Your voicemail inbox may be empty. Check Genesys UI to confirm.
"Access denied" when downloading The voicemail may have been deleted. Try refreshing the page.
Forward not working Ensure the recipient user/group exists and has voicemail enabled.
Session expired Log out and log back in to get a fresh token.
Download/Forward/Delete taking too long Large operations are processed in batches. Keep the window open and wait for completion.

API Endpoints

For developers and advanced users.

Note: The application uses POST for batch operations to send JSON payloads with voicemail IDs. Internally, it makes the appropriate HTTP method calls (DELETE, POST) to the Genesys Cloud API.
Pages
Endpoint Method Description
/ GET Home/login page
/dashboard GET Voicemail dashboard
/download GET Download page with selection UI
/forward GET Forward page with selection UI
/delete GET Delete page with selection UI
/logout GET Clear session and logout
/documentation GET Documentation page
OAuth
Endpoint Method Description
/login POST Initiate OAuth flow
/callback GET OAuth callback handler
Voicemail Operations
Endpoint Method Description
/download/<message_id> GET Download single voicemail as WAV
/download-bulk POST Download multiple voicemails as ZIP (accepts JSON payload with voicemail_ids)
/api/forward POST Forward voicemails (batch - accepts JSON payload with voicemail_ids, target_id, target_type)
/api/delete POST Delete voicemails (batch - accepts JSON payload with voicemail_ids)
API Endpoints (JSON)
Endpoint Method Description
/api/voicemails GET List all voicemails (JSON, paginated)
/api/voicemails/stats GET Get voicemail statistics (JSON)
/api/search/users GET Search users by name/email
/api/search/groups GET Search groups by name
Utility
Endpoint Method Description
/health GET Health check endpoint
Genesys Cloud API Calls

The application internally makes these calls to Genesys Cloud API:

Genesys API Method Description
/api/v2/voicemail/messages POST Forward/copy a voicemail
/api/v2/voicemail/messages/{messageId} DELETE Delete a single voicemail
/api/v2/voicemail/me/messages GET Get user's voicemails
/api/v2/users/search POST Search users
/api/v2/groups/search POST Search groups
